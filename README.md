# میز تست سخت‌افزار و اینترنت — توس آراکس (نسخه ۲.۰)

تست آنلاین ماوس، کیبورد (۱۰۰٪/۸۰٪/۷۵٪/۶۰٪)، مانیتور، صدا و میکروفن، دسته بازی، وب‌کم و سرعت اینترنت.

## نصب
کل پوشه را در `public_html` (یا هر زیرپوشه) آپلود کنید. نیازمند PHP 8.0 به بالا است. نسخه‌ی قدیمی (`index.php`, `feedback.php`, `net/`, `sounds/`, `test2.html`, `footstep*.wav` ریشه) را پاک کنید.

## ساختار
- `config.php` — نام سایت، آدرس canonical، ایمیل دریافت نظرات (تنها فایلی که باید ویرایش کنید)
- `content/faq.php` — سوالات متداول؛ هم در صفحه و هم در JSON-LD استفاده می‌شود
- `views/` — هر بخش صفحه
- `assets/css/style.css`, `assets/js/` — ماژول‌های ES (`modules/` برای هر تست، `lib/` برای کدهای مشترک)
- `api/` — `ping.php`, `download.php`, `upload.php`, `feedback.php`

## نکات
- `canonical` در `config.php` همان آدرس قبلی است؛ اگر صفحه جای دیگری منتشر می‌شود اصلاحش کنید.
- ارسال ایمیل با `mail()` است؛ اگر نرسید، تنظیمات ایمیل هاست را بررسی کنید.
- سقف حجم تست سرعت: دانلود ۹۶MB و آپلود ۴۸MB در هر اجرا (ثابت‌ها در `assets/js/modules/network.js`).
- CSP سخت‌گیرانه فعال است؛ از اسکریپت/استایل inline یا CDN خارجی استفاده نکنید.
